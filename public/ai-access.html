🤖 AI Tool Access to Documentation

✅ Solution Implemented!
Your documentation is now fully accessible to AI tools like ChatGPT and Claude through JSON API endpoints.

The Problem (Now Solved)

The main viewer page at https://y1.andiami.tech/docs-viewer is a Single Page Application (SPA) that requires JavaScript to load content. AI tools cannot execute JavaScript.

The solution: Use the JSON API endpoints below instead - no JavaScript required!

🚀 Quick Access for AI Tools (Recommended)

⭐ Get ALL Documentation in ONE Request

https://y1.andiami.tech/docs-viewer/api/ai-all

Returns: Complete content of ALL documents in a single JSON response. Perfect for AI tools!

📋 LLM Configuration File

https://y1.andiami.tech/docs-viewer/llms.txt

Returns: Plain text instructions for AI tools on how to access documentation

Available API Endpoints

1. Get ALL Content (Best for AI)

https://y1.andiami.tech/docs-viewer/api/ai-all

Returns: All documents with full content in one JSON response

Options: ?project=name for single project, ?limit=50 to limit docs, ?summary=true for metadata only

2. Get Project Docs with Content

https://y1.andiami.tech/docs-viewer/api/ai-docs?project=workspace-documentation&bulk=true

Returns: All files with full content for a specific project

3. List All Projects

https://y1.andiami.tech/docs-viewer/api/projects

Returns: JSON array of all documentation projects (6 projects available)

4. List All Files in a Project

https://y1.andiami.tech/docs-viewer/api/docs?project=workspace-documentation

Returns: JSON tree of all files (100+ markdown documents)

5. Get Single Document Content

https://y1.andiami.tech/docs-viewer/api/content?project=workspace-documentation&file=PM2-NATIVE-MEMORY-ARCHITECTURE.md

Returns: JSON with full document content + metadata

6. Search Across All Projects

https://y1.andiami.tech/docs-viewer/api/ai-docs?search=authentication

Returns: Search results with context snippets across all documentation
