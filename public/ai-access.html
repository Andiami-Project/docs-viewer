🤖 AI Tool Access to Documentation

✅ Solution Implemented!
Your documentation is now fully accessible to AI tools like ChatGPT and Claude through JSON API endpoints.

The Problem (Now Solved)

The main viewer page at https://y1.andiami.tech/docs-viewer is a Single Page Application (SPA) that requires JavaScript to load content. AI tools cannot execute JavaScript.

The solution: Use the JSON API endpoints below instead - no JavaScript required!

Available API Endpoints

1. List All Projects

https://y1.andiami.tech/docs-viewer/api/projects

Returns: JSON array of all documentation projects (6 projects available)

2. List All Files in a Project

https://y1.andiami.tech/docs-viewer/api/docs?project=workspace-documentation

Returns: JSON tree of all files (100+ markdown documents)

3. Get Document Content

https://y1.andiami.tech/docs-viewer/api/content?project=workspace-documentation&file=PM2-NATIVE-MEMORY-ARCHITECTURE.md

Returns: JSON with full document content + metadata

How to Use with ChatGPT

Step 1: List Available Documentation

Ask ChatGPT to fetch:

https://y1.andiami.tech/docs-viewer/api/docs?project=workspace-documentation
Step 2: Read a Specific Document

Pick any file from the list and ask ChatGPT to fetch:

https://y1.andiami.tech/docs-viewer/api/content?project=workspace-documentation&file={filename}

Replace {filename} with the actual filename (e.g., PM2-NATIVE-MEMORY-ARCHITECTURE.md)

Example Prompts for ChatGPT

  • "Please fetch this URL and list all available documentation: https://y1.andiami.tech/docs-viewer/api/docs?project=workspace-documentation"
  • "Please fetch and summarize this document: https://y1.andiami.tech/docs-viewer/api/content?project=workspace-documentation&file=PM2-NATIVE-MEMORY-ARCHITECTURE.md"
  • "Find all files with 'ARCHITECTURE' in their name from this API: https://y1.andiami.tech/docs-viewer/api/docs?project=workspace-documentation"
